# Flask Chat App 💬

A real-time chat application built with Flask and Socket.IO.

## Features

- 🔐 User Registration & Login
- 🍪 JWT Authentication (Cookies)
- 💬 Real-time Messaging
- 📜 Chat History
- 🟢 Online / Offline Status
- 🔔 Unread Message Counter

## Technologies Used

- Python
- Flask
- Flask-SocketIO
- SQLite
- HTML
- CSS
- JavaScript

## Installation

```bash
git clone https://github.com/ayyan915/flask-chat-app.git
cd flask-chat-app
pip install -r requirements.txt
python app.py
```
